# MouseCopyPasteDelete

Утилита для Windows 10/11, которая автоматически копирует выделенный мышью текст в буфер обмена, вставляет по двойному клику на активном поле ввода и удаляет выделение жестом ЛКМ+ПКМ.

## Возможности

- Работа в системном трее (без консольного окна в release-сборке).
- Глобальный низкоуровневый хук мыши (`WH_MOUSE_LL`).
- Автоматическая отправка `Ctrl+C` после выделения (движение мыши больше порога).
- Защита от ложных срабатываний (всегда включена): копирование считается успешным только если буфер обмена реально изменился, а повтор того же текста (например, при изменении размера окна) не вызывает повторный звук/обработку.
- Вставка по двойному клику левой кнопкой на активном поле ввода (`Ctrl+V`), опционально.
- Удаление выделенного: удерживая ЛКМ (выделение), нажмите ПКМ — выделение удаляется (`Delete`), контекстное меню не показывается.
- Игнорирование простых кликов и выделения с зажатыми модификаторами.
- Настройки: порог движения, задержка, чёрный список процессов, горячая клавиша, звук после копирования (системный звук или свой WAV через выбор файла).
- В чёрный список по умолчанию добавлены распространённые скриншотеры: `SnippingTool.exe`, `ScreenClippingHost.exe`, `Skrinshoter.exe`, `ShareX.exe`, `Greenshot.exe`, `Lightshot.exe` (их можно убрать/изменить в настройках).
- Пункт трея показывает текущее состояние авто-копирования галочкой, подсказка иконки тоже обновляется.
- Сохранение настроек в JSON в `%APPDATA%\autoclipx\autoclipx-rs\config\settings.json`.
- Один экземпляр (named mutex).
- Автозапуск с Windows через `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
- Логирование в `app.log` (рядом с exe, иначе в `%LOCALAPPDATA%`, иначе во временной папке).

## Сборка

```bash
cargo build --release
```

Готовый `.exe`: `target/release/mousecopypastedelete.exe`.

## Запуск

Запустите `mousecopypastedelete.exe` — иконка появится в системном трее.

1. Выделите текст в любом приложении и отпустите левую кнопку мыши.
2. Текст окажется в буфере обмена.
3. Включить/выключить авто-копирование можно через меню трея (галочка) или горячую клавишу (по умолчанию `Ctrl+Alt+C`).
4. Если включена вставка по двойному клику, двойной клик на распознанном активном поле ввода отправляет `Ctrl+V`. В остальных местах двойной клик работает как обычно.

Пункт меню «Настройки...» открывает окно с параметрами.

## Настройки

| Параметр | По умолчанию | Описание |
|---|---|---|
| `enabled` | `true` | Авто-копирование включено |
| `move_threshold` | `5` | Минимальное движение мыши в пикселях |
| `copy_delay_ms` | `80` | Задержка перед отправкой `Ctrl+C` |
| `blacklist` | скриншотеры по умолчанию | Имена процессов, где копирование/вставка не выполняются |
| `toggle_hotkey` | `Ctrl+Alt+C` | Глобальная горячая клавиша вкл/выкл авто-копирования (в UI задаётся нажатием комбинации) |
| `sound_feedback` | `false` | Звук после успешного копирования |
| `sound_name` | `SystemAsterisk` | Системный звук (`SystemAsterisk`, `SystemExclamation`, `SystemHand`, `SystemQuestion`, `SystemStart`, `Beep`) |
| `sound_file` | `""` | Свой `.wav` (выбирается диалогом; имеет приоритет над `sound_name`) |
| `paste_on_double_click` | `true` | Вставка (`Ctrl+V`) по двойному клику на активном поле ввода |
| `delete_on_lmb_rmb` | `true` | `copy paste del`: удерживая ЛКМ, нажать ПКМ — удалить выделение (`Delete`) |
| `autostart` | `false` | Автозапуск с Windows |

Формат горячих клавиш: `Ctrl+Alt+C`, `Win+Shift+F5`, `Alt+Insert` и т. п.

## О ложных срабатываниях

При изменении размера окна курсор перемещается с зажатой левой кнопкой — это похоже на выделение текста. Утилита проверяет номер последовательности буфера обмена (`GetClipboardSequenceNumber`) до и после `Ctrl+C` и запоминает последний успешно скопированный текст: если буфер не изменился или текст тот же, повторный звук/обработка не выполняются.

## Жест удаления (ЛКМ+ПКМ)

1. Выделите текст левой кнопкой и **не отпускайте ЛКМ**.
2. Нажмите **ПКМ**.
3. Выделенный текст удаляется (`Delete`), ПКМ перехватывается (контекстное меню не открывается).

## Известные ограничения

- **Права администратора.** Если целевое приложение запущено с повышенными правами, утилита тоже должна быть запущена от администратора.
- **Защищённые приложения.** Банковские клиенты, игры с античитами и некоторые DRM-приложения могут блокировать глобальные хуки и `SendInput`.
- **Эвристика выделения.** Проверка изменения буфера и дубликатов снижает число ложных срабатываний, но редкие случаи всё ещё возможны; помогает чёрный список процессов.
- **Скриншотеры.** Оверлеи для выделения области могут конфликтовать с авто-копированием; основные процессы уже в чёрном списке по умолчанию, но у некоторых инструментов может быть другой процесс — добавьте его имя вручную.
- **Двойной клик / вставка.** Жест заменяет нативный двойной клик на распознанном поле ввода (обычно выделение слова). Детекция поля — эвристика по HWND-классу/GUI-фокусу (`Edit`, `RichEdit` и похожие). В браузерах/Chromium/Electron/кастомных UI поля могут не распознаваться — тогда двойной клик сохранит обычное поведение. При необходимости отключите опцию или добавьте процесс в чёрный список.
- **Горячая клавиша.** При конфликте с другой программой регистрация не удастся; утилита продолжит работать без горячей клавиши.
- **Окно настроек.** Использует `eframe`/`egui` (OpenGL/glow); при первом открытии возможна небольшая задержка.

## Структура проекта

```
Cargo.toml
src/
  main.rs        — точка входа, глобальное состояние
  hooks.rs       — хук мыши WH_MOUSE_LL, выделение и двойной клик-вставка
  send_input.rs  — отправка Ctrl+C/Ctrl+V и воспроизведение звука
  clipboard.rs   — проверка буфера обмена Windows
  settings.rs    — модель и загрузка/сохранение настроек
  hotkey.rs      — глобальная горячая клавиша и сообщения потоку трея
  tray.rs        — иконка/меню трея и окно настроек (egui)
  autostart.rs   — автозапуск через реестр
  logger.rs      — файловое логирование
```
